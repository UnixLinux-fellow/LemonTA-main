LemonTA 登录功能流程

方案A：纯 openid 登录 — 微信 openid 即唯一身份凭证，云数据库按 _openid 自动隔离

一、启动时自动静默登录 — app.js onLaunch

首屏即刻渲染，无需等待 else 无缓存 Note over GD: isLoggedIn = false end App->>App: ensureLogin() Note over App: 防重：_loginPromise 单例 alt globalData.openid 已有 App-->>App: resolve(openid) 直接返回 else 需要获取 App->>CF: callFunction({name:'login'}) Note over CF: cloud.getWXContext() CF-->>App: { openid, appid, unionid } App->>GD: openid = xxx, isLoggedIn = true App->>Storage: setStorageSync('userInfo', merged) end App->>DB: users 集合 → loadUserProfile() DB-->>App: { avatarFileID, nickName } App->>GD: 同步头像昵称 App->>DB: config 集合 → loadAppConfig() DB-->>App: { downloadUrl, ... } App->>GD: 同步运营配置 App->>DB: designs 集合 → refreshDesigns() Note over DB: 按 _openid 自动过滤 DB-->>App: [design1, design2, ...] App->>GD: designs = [...] Note over GD: 全局数据就绪，各页面可用

sequenceDiagram participant User as 用户 participant Profile as profile.js participant App as app.js participant Cloud as wx.cloud participant DB as users 集合 participant GD as globalData User->>Profile: 点击编辑按钮(铅笔图标) Profile->>Profile: openEditModal()
